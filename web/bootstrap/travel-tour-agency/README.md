# Vespera — Travel Tour Agency

A polished, responsive **tour discovery website** with destinations, packages, itineraries, booking forms, and traveler notes. Built for tour operators, travel houses, and small-group agencies.

**House:** Vespera  
**Brand:** `#612D53`  
**Prefix:** `vs-*`

Built with **HTML, CSS, JavaScript, Bootstrap 5, Bootstrap Icons**, Playfair Display, and Manrope.

## Template Overview

| Property | Value |
|---|---|
| Template Name | Travel Tour Agency (Vespera) |
| Category | Travel, Tours, Hospitality |

| License | Free to use and customize |

## Features

- Sticky tour-house navigation with skip link and mobile menu
- Dark plum hero with destination / month / travelers / trip-type search
- House story, group-size chips, and animated metrics
- Destination cards that filter the package board
- Filterable packages (cultural, culinary, adventure, wellness) with search
- Sample itineraries with day-by-day timelines and tab switching
- What’s included grid (stays, meals, guides, transfers)
- Guide profiles for Maya, Kavya, Arjun, and Anika Poluru
- Booking form with trip pick, departure month, traveler stepper, room, local draft
- Traveler notes, Austin desk hours (today highlighted), map panel, FAQ, newsletter
- Accessible labels, semantic HTML, and reduced-motion handling

## Sections

1. **Hero** — house identity and tour search
2. **The house** — story and metrics
3. **Destinations** — Kyoto, Lisbon, Oaxaca, Marrakech, Iceland, Kerala

## Getting Started

```bash
cd web/bootstrap/travel-tour-agency
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.

## Customization

1. Replace the house name, story, contact details, and desk hours.
2. Update destinations, package prices, group sizes, and departure months.
3. Swap itinerary days and guide biographies.
4. Connect the booking form to your reservation desk.
5. Adjust colors in `assets/css/style.css` (`--vs-primary` is `#612D53`).
