# Helio — Online Course Platform

A polished, responsive **e-learning landing page** with a course catalog, instructor profiles, learning paths, and pricing. Built for online schools, cohort products, and education brands.

**School:** Helio  
**Brand:** `#F5AD18`  
**Prefix:** `hl-*`

Built with **HTML, CSS, JavaScript, Bootstrap 5, Bootstrap Icons**, Fraunces, and Outfit.

## Template Overview

| Property | Value |
|---|---|
| Template Name | Online Course Platform (Helio) |
| Category | Education, E-learning |
| Framework | Bootstrap 5 |
| Interaction | Vanilla JavaScript |
| License | Free to use and customize |

## Features

- Sticky campus navigation with skip link and mobile menu
- Dark gold hero with topic / catalog / level / length search
- School story, studio chips, and animated metrics
- Filterable course catalog (product, design, data, engineering, leadership, growth)
- Learning paths with sequenced studios
- Instructor profiles that prefill the enroll form
- Monthly / yearly pricing toggle (Audit, Studio, Campus)
- Enrollment form with course, path, plan, faculty, local draft
- Alumni notes, FAQ, newsletter
- Accessible labels, semantic HTML, and reduced-motion handling

## Getting Started

```bash
cd web/bootstrap/online-course-platform
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.

## Customization

1. Replace the school name, story, contact details, and hours.
2. Update course titles, prices, seats, and instructor bios.
3. Swap faculty (Subbu, Maya, Kavya, Arjun, Anika Poluru).
4. Connect the enrollment form to your campus or LMS.
5. Adjust colors in `assets/css/style.css` (`--hl-primary` is `#F5AD18`).
